## 🌟 遊戲特色與十大核心系統

1. 🗺️ **大東亞天下全圖 (30 邦國)**：
   * 包含中原 22 州郡 + 8 大異域邦國（東瀛【邪馬台國】、海東【夷州・台灣島】、朝鮮【三韓帶方】、漠北【單于庭】、遼西【白狼山】、西域【大宛汗血國】、青藏【西羌積石山】、極南【八納洞】），全地圖 52 條征戰與海東商道！
2. 👑 **自創君主立足模式**：自訂姓名、頭像、立足都城、旗幟色彩與 400 點五維屬性。
3. 🧑‍💼 **120 位名將與隱世仙真**：含南華老仙（智100）、于吉仙人（智98）、神卜管輅（智97）、槍神童淵（武99）、卑彌呼、沙摩柯等。
4. 📈 **RPG 戰功升級與朝廷官爵**：武將升級自由加點，朝廷晉封大將軍、丞相、九錫稱王乃至受禪稱帝！
5. 💍 **家族子嗣府與名將聯姻**：與心儀名將結為連理，誕生子嗣名師教導，年滿 16 歲及冠出仕！
6. 💎 **36 件上古神兵秘寶**：軒轅夏禹劍、太公六韜、大宛汗血天馬、親魏倭王金印、女媧五色石等。
7. 🌪️ **19 部史詩劇情與動態天災人禍**：青梅煮酒、借東風、赤地蝗災、江河決堤、傷寒大疫之戰略抗災抉擇。
8. 🌸 **四季時令天候加成**：春生農耕增益、夏長火計商業、秋收大徵糧草、冬藏減耗。
9. 🌐 **多人線上 WebSocket 房間對戰**：2～8 人線上房間開局、陣營認領、回合同步推進、即時公頻密信聊天室與同機多人模式 (Hot-seat)。
10. ⌨️ **極致流暢操作與快速鍵**：我方領地快速導航膠囊、金色龍冠呼吸光環、相鄰敵城綠色雷達脈衝鎖定出征。

## ⌨️ 鍵盤快速鍵操作指南

* `Space` / `Ctrl + Enter`：**結束本月**（時間推進）
* `[` / `]` 或 `Tab`：**切換上一座 / 下一座己方城池**
* `A`：**出征討伐** (Attack)
* `M`：**部隊移動** (Move)
* `R`：**徵兵備戰** (Recruit)
* `D`：**農商開發** (Develop)
* `S`：**人才探索** (Search)
* `Esc`：**取消選取 / 關閉彈窗**
