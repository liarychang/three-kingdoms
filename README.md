```mermaid
    PlayerB->>Server: 加入房間 (輸入 TK-1208)
    PlayerA->>Server: 認領勢力【曹操】並點擊就緒
    PlayerB->>Server: 認領勢力【劉備】並點擊就緒
    PlayerA->>Server: 點擊【🔥 開始逐鹿】
    Server-->>PlayerA: 廣播戰局啟動
    Server-->>PlayerB: 廣播戰局啟動
    Note over PlayerA,PlayerB: 戰局即時同步：出征、徵兵、公頻/密信聊天、回合同步推進
```

1. **建立房間**：點擊頂部 **`🌐 多人`**，輸入暱稱建立專屬 4 位房間號。
2. **加入與認領**：好友輸入房間號加入，各自認領不同君主勢力。
3. **即時廣播**：出征討伐、徵兵、研發全域即時廣播，全員結束本月後統一推進下月！
4. **👥 同機熱座模式 (Hot-seat)**：一台電腦上支援 2～8 位玩家輪流操控不同勢力。

## 🛡️ 第十一章：防誤觸重整與智慧自動存檔恢復

```mermaid
flowchart TD
    A["🕹️ 玩家正常遊玩"] -->|推進月份/征戰獲勝/探索招募| B["⚡ 即時自動存檔 (Auto-Save)"]
    A -->|切換 App / 鎖定螢幕| B
    A -->|誤按 F5 / Ctrl+R / 關閉分頁| C{"🛡️ beforeunload 攔截"}
    C -->|彈出防誤觸提示| D["寫入最後存檔"]
    D --> E["重新整理完成"]
    E --> F["👑 首頁頂部流光橫幅：發現未完戰局"]
    F -->|點擊 ⚡ 繼續戰局| G["0.1秒無縫回到戰場！"]
```

1. **雙重防誤觸攔截**：戰局進行中若誤觸 F5、Ctrl+R 或關閉分頁，瀏覽器立即彈窗確認，並在離開前瞬間保存進度。
2. **全時段自動存檔**：每回合推進、重大操作、App 切換背景皆自動寫入 `LocalStorage`。
3. **一鍵戰局恢復**：重新載入網頁後，開局選單頂部常駐金色流光橫幅 **`⚡ 發現上次未完戰局【君主・勢力】`**，點擊 **`[⚡ 繼續戰局]`** 即可 0.1 秒無縫重返戰場！
