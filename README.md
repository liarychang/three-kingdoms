## ⌨️ 鍵盤快速鍵操作指南

* `Space` / `Ctrl + Enter`：**結束本月**（時間推進）
* `[` / `]` 或 `Tab`：**切換上一座 / 下一座己方城池**
* `A`：**出征討伐** (Attack)
* `M`：**部隊移動** (Move)
* `R`：**徵兵備戰** (Recruit)
* `D`：**農商開發** (Develop)
* `S`：**人才探索** (Search)
* `Esc`：**取消選取 / 關閉彈窗**
